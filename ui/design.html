Notes / 已知問題

已知 UI 問題（本輪不修）

  • Button nowrap at 390px: button { white-space: nowrap; } 會讓超長按鈕文字在 390px 時溢出，除非包在 .actions 內換行。建議未來 review 是否允許極端文字時自動換行。
  • Table header alignment: 長 Template 名稱在窄欄位會撐高整列。建議 review 是否加入 min-width 或固定欄寬。
  • Print preview height: .print-preview 依賴內容高度，若內容為空可能過短。
  • Dialog overlay: 目前沒有全頁遮罩（overlay），對話框直接在文流中顯示，未來可評估是否需要遮罩。
  • Language drop-down width: select#locale 在 390px 下若選項名稱過長可能被撐開，尚未驗證。
  • Photo strip overflow: .strip 使用 overflow-x: auto，在 390px 下可能出現水平滾動，此為刻意設計但需確認車用體驗。

這些問題只記錄在 Showcase，不在本輪修改任何產品頁面。
