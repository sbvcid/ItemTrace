# ItemTrace — 拍下來，AI 幫你記住，以後找得到

完整的手機優先 MVP（最小可用產品），用 AI 和照片把日常物品紀錄下來。

**核心流程**：隨手拍 📷 → AI 自動整理 ✨ → 一鍵存起來 ✓ → 日後快速找回 🔍

## 產品特色

- **手機優先設計**：在手機上拍照、整理、搜尋；電腦作為伺服器
- **零打字直接存**：拍幾張照片，AI 自動辨識名稱、品牌、型號、序號，建議都對就一鍵存檔
- **AI 可靠辨識**：基於使用者驗收，不自動蓋掉人工修改；失敗時照片保留，可原地重試
- **紀錄持續完善**：已存的物品可追加新照片、AI 重新理解；支援編輯名稱、品牌、狀況備忘
- **秒級尋回**：搜尋名稱、品牌、型號、序號任意一部分，即時顯示匹配的物品
- **本地隱私**：所有資料存在 SQLite 和檔案，無雲端、無帳號、無訂閱
- **雙語支援**：繁體中文和英文，輕按切換
- **打標籤與列印**：為物品列印 QR 碼標籤，方便掃描回查

## 需要什麼

- **Windows / macOS / Linux** 系統運行伺服器
- **Python 3.11 以上**
- **任何手機或平板**（同一個 Wi-Fi）
- **可選 AI**：Google Gemini、OpenRouter 或自訂 OpenAI 相容 API

## 快速開始

### 1. 安裝依賴

```bash
pip install -r requirements.txt
```

### 2. 初始化

```bash
python shopctl.py init       # 建立 config.json 與 catalog.db
```

### 3. 啟動服務

```bash
python serve.py              # http://127.0.0.1:8731/
```

Windows 用戶可以直接雙擊 **`啟動 ItemTrace.bat`**。

### 4. 在電腦上試試

打開瀏覽器：**<http://127.0.0.1:8731/>**

### 5. 從手機連進來

編輯 `config.json`：

```json
{
  "server_host": "0.0.0.0",
  "allow_lan": true
}
```

重啟服務，在手機上連到同一個 Wi-Fi，打開 `http://<電腦IP>:8731/`

> **安全提示**：`0.0.0.0` 代表開放整個區網。這是為家庭使用設計的，
> **不要放在公開網路**。用完記得改回 `127.0.0.1`。因為沒有登入機制，
> 非 loopback 卻沒設 `allow_lan: true` 時，服務會拒絕啟動。

## 使用流程

### 📷 拍照記錄

1. 點擊 **「📷 開始拍照記錄」** 按鈕
2. 拍多張照片（正面、規格標籤、銘牌、配件均可）
3. AI 自動分析這些照片，提示：
   - ✓ **看見**：高置信度的結果（如果清楚地看到序號）
   - ~ **推測**：低置信度的結果（如果是猜測的）
4. 檢查 AI 的建議是否正確；可修改任何欄位
5. 點擊 **「✓ 存起來」** —— 完成！

### 🏠 首頁與搜尋

- **最新紀錄**：保存後立即顯示在首頁頂部，並短暫高亮
- **搜尋任何部分**：搜尋名稱、品牌、型號、序號末碼，都能快速找到
- **詳細資訊卡片**：點擊任何物品查看完整詳情

### 📝 編輯與追加

在物品詳情頁：

- **編輯欄位**：修改名稱、品牌、型號、分類、外觀狀況等
- **📷 加入照片**：為既有物品追加新照片
- **✨ AI 重新整理**：當追加新照片時，AI 在既有資訊的基礎上重新理解
- **複製序號**：一鍵複製序號到剪貼簿

### 🔍 搜尋與尋回

- 在首頁搜尋框輸入任何關鍵字
- 支援模糊搜尋（部分品牌、型號、序號末位）
- 即時篩選結果，點擊進入詳情

### 🏷️ 列印標籤（選用）

- 在物品頁點擊 **「列印」** 按鈕
- 選擇標籤範本、印表機
- 看預覽後一鍵列印 QR 碼標籤
- 掃碼回查物品詳情

## 架構

```
手機 / 電腦瀏覽器
    ↓ (HTTP)
ItemTrace 伺服器 (FastAPI)
    ├── SQLite 資料庫 (catalog.db)
    ├── 原始照片儲存 (files/ 目錄)
    ├── AI 分析引擎 (可選，整合 Gemini / OpenRouter / Custom)
    ├── 列印管線 (Chromium + GDI)
    └── 搜尋 & 檢索
```

**特色**：
- 零建置前端（純 HTML/CSS/JavaScript，無框架）
- 無外部依賴（只有 FastAPI 用於 HTTP）
- 原始照片永不覆寫；新拍照自動編號
- 所有資料本地化；無雲端同步

## 配置說明

`config.json` 可配置項：

| 欄位 | 預設 | 說明 |
|---|---|---|
| `server_host` | `127.0.0.1` | 綁定位址 |
| `allow_lan` | `false` | 是否允許區網存取 |
| `server_port` | `8731` | 連接埠 |
| `max_upload_bytes` | `25165824` | 單一上傳檔案上限（24 MB） |
| `max_upload_files` | `20` | 一次上傳最多檔數 |
| `max_image_pixels` | `50000000` | 單張圖片像素上限（50 MP） |
| `analyze_per_minute` | `10` | 每分鐘 AI 呼叫上限 |
| `enable_docs` | `false` | 是否啟用 API 文件 (`/docs`) |

## AI 配置（選用）

1. 進入 **<http://127.0.0.1:8731/settings>**
2. 選擇 AI Provider：
   - **Google Gemini**（免費 tier 可用，推薦）
   - **OpenRouter**（支援多種模型）
   - **自訂 OpenAI 相容 API**
3. 輸入 API key 並測試連線
4. 回到物品頁點 **「✨ AI 重新整理」** 就能使用

> API key **不會離開這台電腦**，存在本地檔案 `tools/ai_config.local.json`（已排除於版本控制）。
> 從手機存取時也不會上傳 key；設定在區網內是開放的，
> 這與「區網裝置本來就能讀寫所有物品資料」的信任模型一致。

## 語言支援

UI 支援繁體中文和英文，可在任何頁面右上角切換（沒有 UI 時按 ⚙️ 設定鍵）。

- **物品資料保持原文**：名稱、品牌、型號、備忘等你輸入的內容不會翻譯
- **只翻譯 UI**：按鈕、標籤、欄位名、錯誤訊息等
- **選擇記在瀏覽器**：不存進資料庫，換裝置各自記憶

## 離線工具

```bash
# 統計各表筆數
python shopctl.py stats

# 完整性檢查（找出資料庫有紀錄但檔案不見的照片）
python shopctl.py verify

# 備份所有資料
python shopctl.py backup
```

備份自動存到 `backups/` 資料夾，最多保留 30 份（可在 config.json 調整）。

## 測試

# 完整測試套件（1049 個測試）

python -m pytest -q tests/test_api.py

所有測試使用暫時資料，不會影響你的真實資料。

## 常見問題

**Q：資料存在哪裡？**  
A：所有資料存在 `config.json` 指定的 `data_root` 目錄（預設當前資料夾）。
`catalog.db`（SQLite）+  `files/`（照片）+ `backups/`（快照）。
整個資料夾可隨時備份或轉移。

**Q：支援多人共享嗎？**  
A：目前設計給單一使用者。無登入系統，區網內有存取就能改所有資料。
多人協作需要未來功能開發。

**Q：可以上傳多少張照片？**  
A：單個物品沒有硬性上限。單次上傳受限於 `max_upload_files`（預設 20 張）、
檔案大小上限 24 MB、圖片像素 50 MP。都可在 config.json 調整。

**Q：手機相機拍不出來怎麼辦？**  
A：可以從手機相冊選取照片，或從電腦拖放上傳。UI 都支援。

**Q：AI 不準怎麼辦？**  
A：直接在 review 畫面改掉。AI 失敗也能存檔（只存照片，沒有 AI 建議）。
日後可追加照片，讓 AI 重新理解。

**Q：可以離線使用嗎？**  
A：可以。沒有設定 AI provider 時，就是純離線拍照 + 手動標籤系統。
一切資料在本地，不需要網路。

## 安全與隱私

- **本地優先**：所有資料存在本機，無任何上傳到雲端
- **防禦桌面攻擊**：
  - Host 白名單（防 DNS rebinding）
  - Origin 驗證（防跨站請求）
  - 自訂標頭檢查（防簡單 CSRF）
  - 媒體附件化（防上傳 HTML 執行）
  - CSP 與 nosniff 標頭
- **資源上限**：請求、檔案、圖片像素都有上限，防止拒絕服務
- **AI key 安全**：已存 key 不外送；測試自訂 API 需臨時 key，每次收集
- **列印管線**：預設啟用沙箱，防止 PDF 惡意程式碼
