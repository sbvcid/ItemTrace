# 10. UX & Interaction Design

本文件定義 ItemTrace V3 的互動模型、畫面規格、多狀態設計、響應式斷點佈局與無障礙（a11y）標準。

---

## 1. 核心互動模型（Core Interaction Model）

ItemTrace V3 依據裝置與情境特性，採取清晰的「雙主場」互動哲學：
1. **行動端主場（Mobile Field Mode）**：
   - **核心任務**：極速擷取（Capture）、現場調閱（Retrieve via QR）、轉手快照（Snapshot）。
   - **互動特徵**：全螢幕無干擾流程、大拇指熱區最佳化、大尺寸觸控標靶（≥ 48px）、避免打字、手勢滑動。
2. **桌上端主場（Desktop Command Mode）**：
   - **核心任務**：深入審核（Focus Review）、照片比對（Compare）、實體列印（Print）、證據交付（Export）。
   - **互動特徵**：左右分欄高效並排、滑鼠滾輪深層縮放、鍵盤全快捷鍵操作、高密度資訊一覽。

---

## 2. 響應式斷點與架構策略（Responsive Strategy）

```text
斷點劃分：
  [ Mobile: < 768px ]      ── 主場：直向握持、拍照建檔、掃碼調閱、單手操作
  [ Tablet: 768px - 1023px ] ── 混合：收合式 Icon Rail、可攜帶式盤點
  [ Desktop: 1024px - 1439px ]─ 標準：左側欄 (240px) + 流暢內容區
  [ Wide: ≥ 1440px ]        ── 寬螢幕：物品履歷雙欄並排（左照片時間軸，右詳細資訊）
```

### 2.1 行動裝置（390px — iPhone / Android 主場）
* **頂部列 (Topbar)**：極簡緊湊（48px）。僅保留品牌識別、全域搜尋圖標與連線狀態指示。
* **底部導覽列 (Bottom Nav)**：固定於螢幕底端，包含 3 個關鍵觸控點：
  - 左：`[ ▤ 物品庫 ]`
  - 中：`[ ◉ 拍照建檔 ]`（突出懸浮圓形主按鈕，半徑 56px，位於大拇指最自然觸及的中心扇形區）
  - 右：`[ ✓ 待確認 ]`（帶有未決建議數字徽章）
* **Capture 模式體驗**：進入時自動隱藏底部導覽列，切換為全螢幕專屬相機工作台。

### 2.2 平板裝置（768px — iPad / Surface）
* 左側採用 64px 緊湊型 Icon Rail，為中央內容釋放最大可視面積。
* 支援橫向分欄檢視（Split View）：左側為物品清單，右側即時展示履歷。

### 2.3 桌面端（1024px ~ 1440px+）
* 左側固定 240px 導覽列，整合主要佇列與系統健康資訊。
* 頂部常駐全域搜尋列（按 `/` 鍵一鍵呼出）。
* 履歷畫面自適應展開：大螢幕下採用大比例雙欄並排，左側照片與時間軸佔 55%，右側身分、識別碼與事實屬性佔 45%。

### 3.4 專注審核工作台（Focus Review — `/review/:id`）

* **左側視窗（60%）**：照片放大鏡。支援按住空白鍵拖曳、滾輪縮放。預設將視窗聚焦於序號標籤所在之照片切片。
* **右側面板（40%）**：
  - 每個待審核項以卡片區塊展示。
  - 識別碼審核卡片提供極具對比度的等寬字體顯示，並提供「✎ 修正後接受」按鈕，點擊後展開即時編輯輸入框。

---

### 3.5 快照並排比對器（Compare — `/i/:id/compare`）

* **頂部工具列**：
  - 左側下拉選單：基準快照 A（例如：2026/10/02 建檔初始，4 張照片）。
  - 右側下拉選單：對比快照 B（例如：2026/10/07 買家退回，3 張照片）。
  - 中間工具：`[ 同步縮放: 開啟 ]`、`[ 90度旋轉 ]`、`[ 增強對比度 ]`。
* **主視窗**：左右 50% 垂直分割畫面。當滑鼠在左圖放大檢視電路板瑕疵時，右圖同比例自動同步平移與縮放。

## 4. 時間軸聚合降噪規則（Timeline Aggregation）

為避免資料庫中的大量技術事件（`events`）淹沒真正有意義的外觀歷程，時間軸套用以下降噪演算法：
1. **快照作為一級骨幹節點（Milestone Nodes）**：
   - 包含照片的快照一律作為大節點呈現，標註拍攝目的標籤（如 `[寄出前]`、`[收回]`）。
2. **同一次編輯的多個欄位自動合併（Session Batching）**：
   - 使用者在 5 分鐘內對同一物品連續修改了「品名」、「品牌」、「備註」，時間軸將其合併為單一事件節點：
     `「由 user 更新了 3 項欄位（品名、品牌、備註）」`，點擊後展開呈現各自的前後值與個別復原按鈕。
3. **AI 建議狀態降噪**：
   - `suggestion.created` 事件預設在時間軸隱藏，僅當該建議被「接受」時，才記錄為：
     `「接受了 AI 建議的 序號: 6LWMF1234567」`。

## 5. 系統狀態反饋設計（UI States）

| 狀態類型 | 具體設計規範 |
|---|---|
| **Skeleton 骨架屏** | 物品履歷載入時，照片區與文字區呈現柔和灰調微光流動骨架屏，禁止使用粗暴的全螢幕 Spinner。 |
| **Empty 空狀態** | - 物品庫為空：繪製精緻的實體物品速寫插圖，文字：「尚未建立任何物品。拿起手機掃描下方 QR Code，立即拍下第一件物品。」<br>- 待確認為空：綠色打勾圖標，文字：「所有草稿皆已確認完畢！目前沒有待辦事項。」 |
| **Error 錯誤狀態** | 採用內嵌可重試卡片（Inline error card），清楚用白話文解釋原因（如「無法載入照片：硬碟目錄權限不足」），並附帶「重試」按鈕。 |
| **Offline 斷線狀態** | 手機頂部滑出黃色輕量橫幅：「目前處於離線狀態，已拍照片安全暫存於手機中，連線恢復時將自動同步。」 |

## 6. 無障礙與鍵盤導引（Accessibility & Keyboard Navigation）

1. **色彩對比度**：所有文字與背景之對比度嚴格滿足 WCAG 2.1 AA 標準（文字 ≥ 4.5:1，大標題與 UI 邊框 ≥ 3:1）。
2. **語意標籤與 ARIA**：
   - 所有的照片均帶有動態生成的 `alt` 屬性（例如 `alt="ITM-0042 正面外觀照片 - 2026/10/05"`）。
   - 彈出對話框（列印、證據包）具備焦點鎖定（Focus Trap），按 `Esc` 鍵立即安全關閉。
3. **全域鍵盤快捷鍵支援**：
   - `/`：全域聚焦搜尋列。
   - `N`：在桌面端開啟新物品匯入/建檔對話框。
   - `J` / `K`：在物品清單或待確認清單上下切換選取項目。
   - `Esc`：關閉所有彈窗或退出放大檢視。
