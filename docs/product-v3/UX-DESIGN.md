# 10. UX & Interaction Design

本文件定義 ItemTrace V3 的生活化互動模型、畫面規格、響應式斷點與多狀態回饋。

---

## 1. 核心互動模型（Core Interaction Model）

ItemTrace V3 專注於 **「隨手拍下、AI 自動整理、秒級找回」**：

1. **手機主場（Mobile Field Mode）**：
   - 專為單手操作優化。
   - 底部中央設置直徑 56px 圓形大快門按鈕，點擊直接拍照。
   - 連拍照片直接進入托盤，拍完 2~4 張直接切入整理預覽，一鍵「存起來」。
2. **桌機主場（Desktop Command Mode）**：
   - 寬幅全域搜尋列常駐頂部，隨時按 `/` 鍵一鍵呼出。
   - 紀錄以優雅的大圖卡片展示，點開可檢視高解析照片與完整規格。

## 3. 響應式斷點策略（Responsive Strategy）

* **手機端 (< 768px)**：大拇指友善，底部固定大快門；卡片單欄/雙欄自適應。
* **平板端 (768px ~ 1023px)**：精簡圖示側欄，支援橫向分割預覽。
* **桌面端 (≥ 1024px)**：寬幅全域搜尋、大比例雙欄圖文展示。

---

## 4. 多狀態回饋規範（UI States）

* **空狀態 (Empty)**：
  - 首頁紀錄為空：溫馨插圖 + 「拍下第一件值得留下的東西吧！拿起手機對準任何裝備、工具或生活好物拍照。」
* **AI 整理中 (Loading)**：
  - 輕柔微光流動（Shimmer），文字提示「✨ AI 正在閱讀照片整理中…」。
* **離線與網路不穩 (Offline)**：
  - 畫面頂部淡黃色膠囊標籤：「離線中，已拍照片安全暫存在手機，連線後自動儲存。」
