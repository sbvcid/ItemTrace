# 6. Main User Journeys (Primary Loop Centric)

本文件定義 ItemTrace V3 的核心使用者旅程。整個系統全面圍繞 **「拍照 → AI 理解與自動整理 → 快速確認（存起來） → 隨時找回」** 的 Primary Loop 構建，進階情境則作為延伸分支。

---

## J1. 首次設定與手機直連（First-time Setup & Device Link）

* **User Goal**：啟動軟體，用手機連進本機服務，並設定 AI 金鑰（非強制，但推薦）。
* **Device**：桌機與手機（同一個 Wi-Fi 區域網路）。
* **Flow**：
  1. 桌機啟動服務（雙擊 bat 或 `python serve.py`），瀏覽器打開首頁。
  2. 首頁頂部友善提示：「📱 拿起手機掃描連線，隨手拍照記錄與整理」。
  3. 點擊展開顯示連線 QR Code（例如 `http://192.168.1.100:8731/`）。
  4. 手機相機掃描，秒開手機端 ItemTrace 介面。
  5. （選用）在桌機或手機進入「設定」，貼上 Google Gemini 或 OpenRouter 的 API Key，點擊「測試」，綠燈通過。
* **Success**：手機成功連入，AI 金鑰就緒，全程不到 1 分鐘。

## J2. ★ 主循環：拍照 → AI 幫忙整理 → 一鍵存起來（The Primary Loop）

這是 ItemTrace 的**靈魂王者旅程**。使用者看到任何值得留下的東西，從開拍到存下紀錄，目標 ≤ 30 秒，全程手打字數為 0。

* **User Goal**：留下手邊新買的 3C、工具器材、或在店面街頭看到的酷東西，完全不想手動打字整理。
* **Device**：手機（單手垂直握持）。
* **Step-by-Step Flow**：
  1. **進入相機**：點擊手機底部正中央的圓形大按鈕「◉ 拍照」，全螢幕進入相機模式。
  2. **連拍 2~4 張**：
     - 快門按一下：拍外觀整體。
     - 快門再按一下：翻過來拍規格標籤貼紙、型號銘板或序號條碼。
     - （選用）拍配件、外盒或周遭細節。
     - 照片每拍一張，縮圖以彈性動畫滑入底部托盤，背景自動非同步上傳。
  3. **完成拍攝，AI 即時理解與整理**：
     - 點擊底部「完成 (3)」。
     - 畫面呈現輕柔紫藍色光暈與流暢進度：「✨ AI 正在理解照片並整理資料…」（約 3~8 秒）。
  4. **呈遞整理結果（主管驗收模式）**：
     - 畫面直接呈現整齊的預覽卡片：
       - **主照片**：清晰置頂展示。
       - **品名**：`ASUS ROG STRIX B650E-F GAMING WIFI`
       - **品牌 / 型號**：`ASUS` · `B650E-F`
       - **分類**：`電腦零件 / 主機板`
       - **序號**：`6LWMF1234567`（直接從標籤貼紙 OCR 抓出，附帶小縮圖對齊）
       - **狀況**：`外觀良好，無氧化，原裝包裝`
     - *(註：若拍攝的是風景、寵物或隨手筆記，AI 靈活歸納為相片紀錄，不硬套 3C 規格欄位)*
  5. **超低摩擦一鍵存起來**：
     - 使用者眼睛掃一眼：「都抓對了！」
     - 點擊底部大按鈕 **「✓ 存起來」**。
     - 紀錄正式生成（`ITM-0042`），彈出提示：「已存下來！」，自動回到首頁。
  6. **（分支：若有錯字）快速微調**：
     - 若發現序號讀錯一個字母，直接點擊該序號文字，鍵盤彈起修改該字元後按「存起來」，同樣不需要重填其他任何欄位。
* **Friction & Handling**：
  - 若網路不穩，照片暫存在手機，連線恢復自動續傳。
  - 若 AI 沒讀出序號，該欄位留空，不跳報錯阻礙，依然可以一鍵存起來。
* **Success**：使用者沒有手動輸入任何一行長型號或序號，30 秒內完成留存，產生強烈成就感。

## J3. 極速調閱與隨手搜尋（Instant Search & Retrieval）

* **User Goal**：幾個月後突然要查某件物品的序號、規格或保固。
* **Device**：桌機或手機。
* **Flow**：
  1. 在搜尋框輸入「4070」或輸入半截序號「1234」。
  2. 搜尋框在 50ms 內即時響應，精確列出該卡片，高亮標記命中之序號。
  3. 點擊卡片展開紀錄詳細，大圖高清展示，規格、型號、序號、購買日期一目了然。
  4. 點擊序號旁「複製」圖示，一秒貼給客服或朋友。
* **Success**：無需翻找紙箱或手機相簿，5 秒內拿到精確資訊。

## J4. 隨手追加照片與生活筆記（Follow-up Additions）

* **User Goal**：物品有了新動態（例如補拍發票、更換了零件、或移到新抽屜），隨手追加。
* **Device**：手機或桌機。
* **Flow**：
  1. 打開該紀錄詳細頁面，點擊「＋ 追加照片 / 筆記」。
  2. 拍下一張發票照片，輸入一句備註「換上了貓頭鷹風扇」。
  3. 點擊儲存，時間軸自然長出一筆新紀錄，原來的照片與身分紀錄完全不受影響。
* **Success**：紀錄隨生活自然生長，無須重新填寫。

---

## J5. 標記離手（Mark as Gone）

* **User Goal**：物品賣出、送人或淘汰，不想在首頁看見，但希望隨時可查歷史。
* **Device**：手機或桌機。
* **Flow**：
  1. 在紀錄詳細頁點擊 `⋯` 選單，選擇「標記為已離手」。
  2. 物品狀態轉為「已離手」，自動自首頁移出。
  3. 需要時切換側邊欄「已離手」，隨時可翻閱完整歷史，亦可隨時一鍵「恢復為在手上」。
* **Success**：首頁保持極致清爽。

## J6. [進階] 列印標籤貼紙與 QR 掃描（Label Printing & QR Binding）

* **User Goal**：為收納箱或包裝盒列印一張實體標籤貼紙，日後相機一掃秒開紀錄。
* **Device**：接有標籤機的桌機。
* **Flow**：
  1. 在紀錄頁點擊「列印標籤」。
  2. 預覽視窗精確展示含有品名、型號、序號與專屬 QR Code 的標籤外觀。
  3. 點擊「列印」，標籤機吐出貼紙。
  4. 貼在物品外盒，手機相機一照 QR，手機瀏覽器 1 秒內喚醒該紀錄頁面。

---

## J7. [進階] 出貨/送修快照與前後比對（Handover Snapshot & Compare）

* **User Goal**：二手賣家出貨前或器材送修前留存外觀狀態，收回時驗證是否遭調包或刮傷。
* **Device**：桌機或平板大螢幕。
* **Flow**：
  1. 出貨前追加照片（封箱外盒與序號特寫）。
  2. 若買家退貨或維修返回，拍照追加「收回現況」。
  3. 點擊「比對快照」，雙視窗 50% 垂直分割，左右同步縮放平移，滑鼠檢視外觀與刮痕。
  4. 客觀確認無誤或記錄狀況。

---

## J8. [進階] 一鍵匯出封存包（Record Package ZIP）

* **User Goal**：面臨拍賣平台糾紛、保險理賠或需要離線完整備份時，出具第三方可信之完整檔案。
* **Device**：桌機。
* **Flow**：
  1. 在紀錄詳細頁點擊 `⋯` →「匯出封存包」。
  2. 系統瞬間打包下載 `ItemTrace-Archive-ITM-0042.zip`。
  3. 打開 ZIP，內含排版專業的 `report.pdf` 報告書、未壓縮原始照片與帶有 SHA-256 哈希的 `manifest.json`。
  4. 可將 PDF 直接呈交拍賣平台客服或保險公司，快速平息爭議。
