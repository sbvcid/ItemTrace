# 2. Target Users & Common Needs

## 2.1 尋找「共同核心」（The Universal Core Need）

過去我們曾誤將「二手 3C 賣家」的防糾紛防調包需求當作產品唯一的核心架構，導致整個系統充斥著「存證」「買家」「退貨」等沉重的商業術語；也曾誤將「個人物品庫 / 資產管理」當成第一層概念，讓使用者背負著「我要坐下來盤點家當、建檔建庫」的心理負擔。

然而，回歸到本質的人性與真實生活情境，無論是自己擁有的物品、剛買的戰利品、手邊的專業器材，還是在商店、街頭、朋友家看到的有趣東西，所有使用者背後存在著**完全相同的強烈痛點**：

> **「我想留下這個東西的資訊備查，但我完全不想花時間整理它。」**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        所有目標使用者的「共同核心需求」                │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 記錄零負擔：拿起手機隨手拍幾張照片，就能把東西記下來，完全不想手動打字。 │
│ 2. AI 自動整理：軟體自己讀出品名、型號、規格、甚至難抄的序號，不需要人來排版。│
│ 3. 查閱秒級反應：幾個月後手邊找不到東西或保固卡時，搜兩個關鍵字就能翻出來。   │
│ 4. 本地自主持有：不需要註冊雲端帳號，資料就在自家電腦裡，隱私安全無憂。     │
│ 5. 拍照即記錄：不只自家物品，逛街看到的型號、朋友的好物、隨手生活紀錄都能拍。 │
└────────────────────────────────────────────────────────────────────────┘
```

## 2.2 使用者畫像（Representative Personas）

我們將目標族群回歸為「需要記下實體世界資訊的廣泛個人」，二手賣家作為高頻進階族群共用同一套底層：

### Persona 1：阿明（3C / 數位設備愛好者 — 廣泛主流）
* **年齡與背景**：28 歲，軟體工程師，喜歡組裝電腦、買客製化鍵盤、耳機、顯卡與各類數位周邊。
* **痛點**：
  - 東西買得多，盒子和說明書堆滿房間；幾個月後要查「這張記憶體時序是多少」「電源瓦數是多少」「保固序號在哪」，得爬去翻機殼或翻垃圾堆。
  - 想記在 Notion 或 Excel，但每次開箱新零件興致勃勃，光想到要手打一堆英文型號跟 16 碼序號就立刻放棄。
* **ItemTrace 對他的價值**：
  - 開箱時拿起手機對著顯卡外觀和彩盒規格標籤拍 3 張照。
  - AI 自動把 `ASUS ROG-STRIX-RTX4070-O12G-GAMING`、序號和規格自動抓好並排版。
  - 看一眼確認無誤，點一下「存起來」。半年後要出保固，直接搜尋「4070」一秒複製序號。

### Persona 2：小涵（攝影器材 / 音樂設備 / 戶外露營控）
* **年齡與背景**：34 歲，平面攝影師，擁有 2 台機身、6 顆鏡頭、穩定器、空拍機與大量配件。
* **痛點**：
  - 鏡頭每顆長得很像，濾鏡口徑、序號、送修紀錄散落在手機相簿與紙本保證書。
  - 出門接案前要檢查帶了哪些器材、租借設備歸還時容易搞混。
* **ItemTrace 對她的價值**：
  - 防潮箱大掃除或借出器材時，拿起手機隨手拍 2 張。
  - AI 讀出鏡頭焦段、光圈與鏡身序號。
  - 記上存放位置「防潮箱 A 櫃」，出勤清點與備查一清二楚。

### Persona 3：老陳（DIY 工具 / 創客 / 模型收藏者）
* **年齡與背景**：42 歲，Maker，工作間有電鑽、起子機、大量耗材、卡尺與模型工具。
* **痛點**：
  - 常常忘記自己有沒有某個規格的鑽頭或零件，逛五金行常買到重複的。
  - 工具盒裡型號密密麻麻，眼力不好手抄非常痛苦。
* **ItemTrace 對他的價值**：
  - 買新工具拆封時拍一下規格貼紙，AI 自動整理留存。
  - 在五金行看到某個規格，手機連回家裡 ItemTrace 搜尋「牧田 18V」，馬上知道家裡現有哪幾隻、規格是什麼。
  - 逛街看到好用的工具也可以順手一拍留存，日後想買直接調閱。

### Persona 4：小凱（二手個人轉售賣家 — Strong Use Case / 進階族群）
* **年齡與背景**：31 歲，業餘在拍賣或社團轉售二手 3C 與球鞋，每月處理 15~30 件物品。
* **痛點**：
  - 除了需要快速登記物品資訊，還非常害怕出貨後遇到買家「調包」或「爭議損壞」。
* **ItemTrace 對他的價值**：
  - **平常**：用最快速度拍幾張照片讓 AI 抓好型號序號，迅速留存。
  - **進階（需要時才用）**：
    - 包裝出貨前，在該記錄點擊「追加照片」，拍下包裝盒與外觀（出貨前外觀比對）。
    - 點擊「列印標籤」，用標籤機印出一張帶有 QR Code 的防水貼紙貼上外盒。
    - 真的遇到爭議時，點擊「產生完整封存包」，一鍵匯出含原始照片與完整歷史的 ZIP 呈交給平台。

## 2.3 使用情境光譜（From Core to Advanced）

我們不再為每個 Persona 切割孤立的產品，而是構建一條平滑演進的光譜：

```text
  [ 日常核心 Core ]  ─────────────────────────►  [ 進階擴展 Advanced ]
   拍照 → AI整理 → 秒查                       列印標籤 → 狀態比對 → 完整封存包
         ▲                                                ▲
         │                                                │
   阿明、小涵、老陳                                     小凱 (賣家)、重度玩家
   (所有人每天都享受)                                (特定時刻安靜召喚)
```

1. **所有人每天都走核心路徑**：
   拍幾張照 → AI 自動整理 → 看一眼確認 → 存下來 → 日後極速搜尋找回。
2. **AI 理解彈性：物品 vs 一般照片**：
   使用者隨手拍下的可能是物品（相機、工具、零件），也可能是路邊風景或生活隨拍。AI 能夠判斷「值得整理成結構化物品紀錄」或「保留為簡單相片備查」，使用者不需要事前分類。
3. **需要的人自然發現進階能力**：
   想印貼紙的人，在卡片右上角 `⋯` 裡找到「列印標籤」；
   要出貨或送修的人，在紀錄中點「追加照片」記錄後續狀況；
   需要提出證明的人，點擊「產生完整封存包」。
4. **普通人完全不受打擾**：
   阿明和小涵從頭到尾不會看到「防調包」「舉證責任」「爭議仲裁」等可怕字眼，他們只會覺得這是一個超級聰明、隨手一拍就能幫自己記住一切的工具。
