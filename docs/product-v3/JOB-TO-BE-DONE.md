# 3. Jobs-to-be-Done & Core Use Cases

## 3.1 真正的主要 Job（Primary JTBD）

> **「我想留下這個東西的資訊，但完全不想花時間整理它；之後當我需要知道它的規格、序號、狀態或細節時，隨手一搜就能立刻找到。」**

「我討厭手打名稱、品牌、型號、序號」是這個痛點最劇烈的具體表現，但產品的本質不是「打字替代器」，而是**「零摩擦的實體記憶助手」**。

### Job 的成分拆解
* **Trigger（觸發時刻）**：
  - 剛買的新品開箱、抽屜翻出一件重要器材、防潮箱大掃除。
  - 在實體店面或五金行看到某個想記下來的型號。
  - 朋友展示了一件很酷的裝備，或是路上看到值得留下的東西。
* **Constraint（關鍵阻礙）**：
  - 我人就站在桌邊、店裡或櫃子前，手上拿著實體東西，我不想走到電腦前坐下來開試算表或 Notion。
  - 型號又長又怪（如 `WH-1000XM5`、`B650E-F`），序號動輒 16 碼英數混雜，手抄極易看錯，痛苦指數爆表。
  - 如果只是拍進手機相簿，兩天後就被寵物照、美食照淹沒；資訊沒有被提煉，日後根本搜不到。
* **Desired Outcome（理想結果）**：
  - 手機拿起來，喀嚓喀嚓拍兩三張，AI 就自己把名稱、規格、序號都看懂並整理好了。
  - 我只要看一眼確認沒問題，按一下「存起來」就搞定。
  - 以後不管過了三個月還是三年，我只要打兩個字或半截序號，這件東西的照片、序號和規格立刻跳出來。

## 3.2 Job Map（主要流程心智對比）

| 階段 | 使用者的目標 | 傳統方式的痛苦障礙 | ItemTrace V3 的回應 |
|---|---|---|---|
| **1. 觸發** | 「這東西我想留下來」 | 光想到要打開 Excel 或 Notion 逐欄建檔就放棄了 | 拿出手機點擊首頁拍照，1 秒啟動 |
| **2. 拍下** | 把外觀跟標籤拍下來 | 拍在手機相簿裡，很快被幾千張生活照淹沒且無法全文檢索 | 連拍幾張（外觀、規格標籤、細節）直通 AI 理解 |
| **3. 提煉** | 把規格、型號、序號整理出來 | 瞇著眼睛一個字一個字手打，打錯 O 和 0 | **AI 自動研讀照片，整齊梳理好品名、規格與序號** |
| **4. 確認** | 確定資料正確 | 一個欄位一個欄位填寫檢查，極度煩躁 | **以「完整整理結果」呈現，看一眼，一鍵「存起來」** |
| **5. 找回** | 在需要時秒級查閱 | 散在聊天室紀錄、相簿截圖、紙盒發票找不著 | 搜尋框打兩個字或末四碼序號，毫秒級跳出完整卡片 |
| **6. 延伸 (選用)** | 換位置、送修、轉手出貨 | 資料固定無法靈活追加 | 隨時點「追加照片與筆記」，資料自然生長 |

## 3.3 情緒型與社交型 Jobs（Emotional & Social JTBD）

* **情緒型 (Emotional)**：
  - **擺脫整理的輕鬆愉悅**：「竟然連這麼難讀的序號標籤都能自動抓出來，完全不用我打字，太爽了！」
  - **隨時找得到的掌控感**：「我清楚知道自己的每件裝備、序號、規格在哪裡，隨手一搜就有。」
  - **資料在手上的安心感**：「純本機優先執行，不聯網也跑得通，隱私安全無憂，資料完全屬於自己。」
* **社交型 (Social - 適用於轉售或借還時)**：
  - 借給朋友或賣二手時，隨手一鍵調出完整照片、規格與序號紀錄，顯得極為專業、細心且負責任。

## 3.4 重新分級的核心 Use Cases 清單

我們將系統 Use Cases 嚴格分為三大層次，確保核心體驗始終輕巧純粹：

### 第一層：Core Experience（日常核心 — 所有人必經）
* **UC-C1：手機拍幾張，AI 自動整理並存下來**
  - 使用者按下拍照，拍下外觀與規格序號貼紙，AI 自動提煉，使用者看一眼點「存起來」，30 秒內完成。
* **UC-C2：極速搜尋找回（名稱、型號、半截序號、特徵）**
  - 輸入「4070」或序號末四碼「1234」，毫秒級精確跳出對應紀錄卡片。
* **UC-C3：瀏覽已整理的紀錄清單與詳情**
  - 卡片式網格展示，大圖優先，規格序號一目了然。
* **UC-C4：隨手追加照片或生活筆記**
  - 補拍一張外觀、隨手備註「更換了副廠線材」，紀錄隨用隨長。

### 第二層：Supporting Experience（日常支援 — 便利生活）
* **UC-S1：選用生活備忘**
  - 隨手記下「購買日期」「購買價格」「保固到期日」「存放位置（如：書房右抽屜）」。
* **UC-S2：狀態切換（在手上 / 已離手 / 作廢）**
  - 東西送人或賣掉時，隨手標記為「已離手」，首頁預設只顯示目前持有的項目，保持清爽。
* **UC-S3：電腦端與手機端跨裝置查看**
  - 手機負責隨手拍，電腦負責舒舒服服大螢幕瀏覽與整理。

### 第三層：Advanced Capability（專業進階 — 特定時刻召喚）
* **UC-A1：列印標籤貼紙（含專屬 QR Code）**
  - 用桌機接標籤機印出貼紙貼在收納箱或外盒，手機相機一掃秒開紀錄。
* **UC-A2：出貨前/送修前狀態快照與前後比對**
  - 二手賣家或器材維修前拍下包裝與外觀，收回時雙視窗並排比對。
* **UC-A3：一鍵匯出紀錄封存包（ZIP 檔案）**
  - 面臨買賣爭議、保險求償或備份存檔時，打包完整原始照片與報告。
* **UC-A4：相機記憶卡大量照片批次匯入**
  - 桌機一次拖入多張照片，依拍攝時間智慧切分成多筆紀錄。
