## 2. 功能變更詳細清單

### 2.1 KEEP（保留不變的核心資產）
這些是過去版本經過嚴格測試且極具價值的核心資產，V3 全數保留：
1. **原始照片不可變性（Original Photo Immutability）**：
   - 存入 `files/<item-id>/original/` 後，嚴禁被覆寫、裁切或靜默刪除。
2. **SHA-256 內容雜湊與重複偵測**：
   - 同一商品重複照片自動略過，不同商品相同雜湊提供警示。
3. **可讀短碼識別碼系統**：
   - `ITM-0001` 作為全球唯一 ID、實體檔案夾名與人類標籤 handle。
4. **序號正規化比對與撞號 409 機制**：
   - 模糊比對去除空白與連字號，跨物品撞號不阻斷、明確由人裁決。
5. **事件驅動稽核與可逆復原**：
   - 每次變更寫入 `events`，單一欄位可精確復原回原值。
6. **本機精確排版列印管線**：
   - Headless Chromium 轉 PDF，PyMuPDF 校正毫米尺寸，win32print 輸出至本機標籤機。
7. **本地資料庫 WAL 安全備份**：
   - `Connection.backup()` 產生自足備份資料夾。
8. **原生 i18n 機制**：
   - `zh-TW` 與 `en` 雙語系，字典集中維護。

### 2.2 CHANGE（重新設計之功能）
1. **Inbox → Capture Session 暫存池**：
   - *原貌*：獨立頁面，上傳後手動點擊分組與建檔。
   - *新貌*：退居為背景通道，手機連拍時每組照片形成一個暫存 Session，點擊「建立」即原子入庫。
2. **Item Detail → 物品履歷（Item Dossier）**：
   - *原貌*：平鋪的資料庫欄位表單。
   - *新貌*：以照片為核心、身分次之、時間軸收尾的故事型履歷。
3. **AI 自動填入 → 背景草稿員（Background Drafter）**：
   - *原貌*：進入頁面後手動點擊「AI 自動填入」，轉圈等待。
   - *新貌*：建檔後自動在背景發起辨識，建議直接長在欄位旁，支援修改後接受。
4. **列印功能 → 實體標籤系統（Physical Labeling）**：
   - *原貌*：列印一張包含資訊的 HTML 紙張。
   - *新貌*：預設包含指向 `/i/ITM-xxxx` 的 QR Code，作為實體回訪飛輪的核心錨點。
5. **Evidence Export → 一鍵證據包（Evidence Package ZIP）**：
   - *原貌*：伺服器產出資料夾，需透過 API 個別下載檔案。
   - *新貌*：一鍵下載單一 ZIP 壓縮包，內建一般人可讀的 `report.pdf` 報告書。

### 2.3 MERGE（合併之功能）
1. **Events + Observations → 統一時間軸（Unified Timeline）**：
   - *理由*：使用者只想了解「這件東西經歷過什麼」。將外觀快照（大節點）與屬性修改事件（小節點）按時間混編於同一時間軸中。
2. **照片列表 + 照片詳細 → 深度照片檢視器（Deep Photo Viewer）**：
   - *理由*：將原本分散的照片網格與來源照片查看，合併為支援全螢幕、手勢/滾輪縮放與角度切換的專用檢視器。

### 2.4 REMOVE（移除之功能）
1. **獨立常駐之 Inbox 導覽項目**：
   - *理由*：Inbox 屬於照片整理心智模型，非物品管理心智模型；若無未整理照片時完全不顯示。
2. **草稿（Draft）物品狀態**：
   - *理由*：SPEC-v1 明確反對 draft，避免「物品是否有效」與「資料是否填妥」糾纏；以「待確認衍生佇列」取而代之。
3. **一級導覽中的範本管理**：
   - *理由*：一般使用者極少天天修改標籤 HTML；收攏至「設定 → 標籤與列印」的進階設定中。
4. **UI 展示頁（`/design`）**：
   - *理由*：不屬於日常生產力路徑，移出產品正式導覽。

### 2.5 ADD（新增之功能）
1. **手機極速連續建檔（Mobile Capture Session）**：
   - 專為單手握持設計的全螢幕拍照流程，支援連拍托盤與原子提交。
2. **專注審核工作台（Focus Review Queue）**：
   - 左側特寫照片、右側建議清單與鍵盤快捷鍵，批次審查效率提升 3 倍。
3. **實體 QR Code 標籤與原生相機直達履歷**：
   - 任何手機鏡頭對準標籤即可在 1 秒內喚醒該物品之專屬網址 `/i/ITM-xxxx`。
4. **快照目的分類（Snapshot Purpose）**：
   - 建檔、取得、寄出前、收回、送修、例行檢查等封閉集合，讓時間軸具備語意。
5. **人類可讀之 PDF 證據報告書（PDF Evidence Report）**：
   - 專業排版，呈列寄出前照片與序號證明，專為平台客服與買家爭議審核設計。
6. **快照雙視窗並排比對器（Side-by-side Snapshot Comparison）**：
   - 專供退貨檢驗與送修前後的真實性辨析。
7. **首頁注意事項列（Attention Strip）**：
   - 整合待確認數量、未整理照片提示、AI 狀態與備份健康度。

## 3. 功能優先級分級（Prioritization Matrix）

### Core（核心功能 — 系統成立的必要支柱）
* **C-1**：手機極速連續建檔流程（Capture Session）。
* **C-2**：物品履歷核心展示（照片、身分、識別碼、狀況）。
* **C-3**：AI 背景自動辨識與建議呈遞。
* **C-4**：逐筆審核工作台（含序號對齊特寫、修改後接受）。
* **C-5**：全域全文與半截序號模糊搜尋。
* **C-6**：帶有專屬 QR Code 的標籤預覽與列印。
* **C-7**：時間軸與轉手快照追加（寄出前、收回等目的）。
* **C-8**：一鍵下載證據包（ZIP 格式，含 `manifest.json` 與原始照片）。

### Important（重要功能 — 決定體驗是否真正流暢）
* **I-1**：首頁注意事項列（待確認、備份提醒）。
* **I-2**：快照雙視窗並排比對檢視器（`/i/:id/compare`）。
* **I-3**：證據包內建排版工整之 `report.pdf`。
* **I-4**：桌機批次拖放匯入與時間分組建議（`/unsorted`）。
* **I-5**：即時撤銷與時間軸歷史單欄位復原（Undo & Revert）。
* **I-6**：Web 端資料健康檢查（Verify）與立即備份按鈕。
* **I-7**：選用事實屬性維護（取得日期/來源、保固到期、存放位置）。

### Optional（選用功能 — 豐富細節，視資源排定）
* **O-1**：卡片視圖與表格視圖之一鍵切換。
* **O-2**：進階篩選（無識別碼物品、保固即將到期）。
* **O-3**：比對模式下的純前端照片濾鏡（對比度增強、照片旋轉）。
* **O-4**：批次列印標籤與批次標記離手。

### Future（未來規劃 — 不在本次實施，但架構保留擴充點）
* **F-1**：局域網 HTTPS 證書一鍵產生，解鎖手機原生 WebRTC 即時取景器。
* **F-2**：PWA Service Worker 快取，支援離線拍照與後續同步。
* **F-3**：全庫 CSV / Excel 匯出。
* **F-4**：物品合併（Merge）與拆分（Split）之完整關係管理。
* **F-5**：AI 自動比對前後快照並以視覺框標註新產生的刮痕瑕疵。

### Reject（明確拒絕的想法 — 記錄理由）

| 被拒絕的想法 | 表面吸引力 | 拒絕理由（為什麼不該做） |
|---|---|---|
| **全面雲端化 / 多人帳號登入** | 可以多裝置無縫使用 | 摧毀 local-first 資料主權原則；大幅增加伺服器成本與隱私風險；本產品定位為單人自用工具。 |
| **完整的 ERP / 庫存進銷存管理** | 滿足微型店鋪的進銷存需求 | 陷入商品規格、庫存扣減、多倉庫移轉的龐大泥淖；ItemTrace 核心是物品的「可信身分與歷程」，不是金流進出。 |
| **內建價格估算與二手市場行情** | 建檔時知道物品價值 | 需引入外部爬蟲與即時行情介面，準確率低且維護成本極高；偏離「可信存證」的主軸。 |
| **任意自訂欄位產生器 (Custom Field Builder)** | 讓使用者愛加什麼欄位就加什麼 | 介面將迅速退化為極度複雜的關聯表單設計器；目前提供的 `attributes` 預設具名鍵已足夠涵蓋 95% 需求。 |
| **自動過期刪除（如一年後自動清理舊物品）** | 節省硬碟空間 | 違反原則 P1（原始證據神聖不可侵犯）。紀錄的價值往往在數年後的法律爭議時顯現，工具絕不可主動替使用者抹除記憶。 |
| **依信心門檻自動全收 AI 建議** | 完全零點擊建檔 | AI 視覺辨識在細微字元（如序號 0 與 O）極易出錯；自動寫入事實將摧毀整個系統的可信基礎。 |
| **在手機端提供完整的 HTML 標籤樣式編輯器** | 手機上也能設計標籤 | 手機螢幕極難進行毫米級排版與 CSS 調試；複雜度與價值不成比例。 |
