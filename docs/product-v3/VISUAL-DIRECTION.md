# 11. Visual Direction: Modern Everyday Utility

本文件確立 ItemTrace V3 的視覺美學語言、色彩階層、排版與照片呈現規範。

---

## 1. 視覺基調：現代生活工藝美學（Modern Craftsmanship）

ItemTrace 的視覺氛圍徹底告別冰冷的「刑事鑑識軟體感」或生硬的「倉儲庫存 ERP 感」，轉向 **「一件手感極佳、隨手記錄生活與裝備的現代工藝工具」**：

* **溫潤可信（Warm & Trustworthy）**：沉著的深藍與溫潤的米白底色，傳達安定感與個人紀錄的珍貴感。
* **輕快俐落（Crisp & Light）**：乾淨的線條、清爽的留白、大尺寸真實照片，像翻閱現代設計生活誌。
* **智慧驚喜（Delightful AI）**：AI 相關元素伴隨輕柔的紫藍微光與 `✨` 火花圖標，傳達「機器替你幹完整理苦力」的愉悅驚喜感。

## 3. 字體排印（Typography Stack）

全面依託作業系統原生優質字體，追求零延遲載入：

```css
/* 介面主文字 */
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang TC", "Microsoft JhengHei", sans-serif;

/* 序號、型號與條碼等寬字體 */
--font-mono: ui-monospace, "SF Mono", "Cascadia Code", Menlo, Consolas, monospace;
```

* **序號專用樣式**：
  序號採用 `var(--font-mono)` 渲染，字距微寬（`letter-spacing: 0.05em`），自動呈現清晰等寬視覺，方便核對。

## 4. 照片呈現原則（Authentic Photos）

1. **主視覺擔當**：卡片使用 4:3 比例，以乾淨的圓角展示實體原貌。
2. **絕不隨意裁切關鍵邊界**：在詳細紀錄中，照片容器提供「完整檢視」，不截斷角部貼紙或序號標籤。
3. **沉浸黑底檢視**：點擊照片進入大圖時，背景切換至微暗色（`#111827`），讓照片主體的高清細節脫穎而出。
